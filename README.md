# Company Portal Website

A responsive company portfolio website developed using HTML, CSS, JavaScript, and Bootstrap. The website showcases company services, team members, business information, and contact details through a modern and user-friendly interface.

## Features

* Responsive design for desktop, tablet, and mobile devices
* Company services showcase
* About Us page
* Team members section
* Contact page
* Modern UI using Bootstrap
* Cross-browser compatibility

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Bootstrap 5

## Project Structure

* `index.html` - Home page
* `about.html` - About Us page
* `service.html` - Services page
* `team.html` - Team page
* `contact.html` - Contact page
* `css/` - Stylesheets
* `js/` - JavaScript files
* `img/` - Images and assets
